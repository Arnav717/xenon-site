// Capabilities

Built For Rooms You Can’t See Into.

No single camera sees the whole building. Xenon makes that irrelevant: every observer contributes what it sees, and every observer gets back the full picture.

01 X-ray

Through-Wall Awareness

Contacts spotted by a teammate appear in your AR view as x-ray bodies, flagged BEHIND WALL whenever scanned structure sits between you.

02 Fusion

Multi-Observer Tracking

Every helmet’s detections fuse in one shared map. Tracks keep stable IDs room to room.

03 LiDAR

Structure Capture

Walk it once. Walls, doors, windows and furniture captured and shared with the team.

// Deployment

Empty Building To Live Picture.

Commodity hardware: one laptop and a few iPhones. No cloud, no Mac, no paid developer account.

01

Start the hub

Run the Python hub on a laptop. Open the console from any browser on the network.

02

Scan structure

Walk each room with a LiDAR iPhone, then Save & Share the model and world map.

03

Join the map

Every other helmet taps Join Map and relocalizes into the shared frame.

04

Operate

Helmets stream pose and contacts. Everyone sees everyone — through walls.
